# MCChecker - 配置文件解析检查工具

基于 Python + NiceGUI 的内网配置文件解析检查工具，支持 XML/JSON 格式配置的在线解析、查看、搜索、对比和版本管理。

## 快速启动

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python main.py
```

服务默认在 `0.0.0.0:50000` 启动，内网其他机器可通过 `http://<服务器IP>:50000` 访问。

## 功能列表

- **文件解析**: 支持 XML/JSON 文件上传或 URL 下载解析，保留完整层级结构
- **标签页管理**: 每个文件独立标签页，互不干扰
- **配置速览**: 收藏关键变量，快速查看核心参数及更新日期
- **全局/局部搜索**: 跨文件检索或单文件检索，覆盖参数及备注
- **全量配置管理**: 配置文件名与下载链接映射，一键全量更新
- **定时自动更新**: 按小时/天设置自动刷新周期
- **版本归档**: 更新自动归档旧版本，支持版本时间轴查看
- **版本对比**: 4类对比场景（当前vs历史、历史vs历史、上传vs当前、上传vs历史）
- **变量绑定**: 配置不同命名变量的等价关系，对比时自动标注
- **工具菜单**: 聚合常用工具链接
- **权限隔离**: 部署者可修改配置，访客仅可查看和临时上传

## 权限说明

- **部署者**（服务端本机 IP）：可修改所有配置，操作持久化保存
- **访客**（其他 IP）：仅可查看和临时上传文件，不会修改服务端数据

## 运行测试

```bash
pytest tests/ -v
```

## 技术栈

- Python 3.9/3.11/3.12
- NiceGUI (Web 框架)
- APScheduler (定时任务)
- 仅使用标准库进行 XML/JSON 解析和文件下载
