# V3 角色与权限矩阵（2026-10-29）

身份、角色、管理员名单、IP 映射是**全局**的，不随工作区复制；工作区不是权限边界。未识别身份只能读公开入口，配置域读也需要已识别身份（`config_read`）。

| 能力 | 访客/未登记 | 成员 | 全局管理员 | 部署者 |
|---|---|---|---|---|
| 会话/工作区/机型列表 | 读 | 读 | 读 | 读 |
| 原速览/文件/搜索/审阅/DL/设置 | 按原规则 | 按原规则 | 按原规则 | 按原规则 |
| 配置管理读（图/参数/总览/差异/历史/导出下载） | 403 | 读 | 读 | 读 |
| 工作区新建/改名/说明、机型增删改 | 403 | 403 | 允许 | 按部署者规则 |
| FixedConfig/版本/参数/绑定/D0/基线/机台写 | 403 | 403 | 允许 | 403（除非同时是全局管理员） |
| 提取计划/合并计划/值导入/导出/恢复/撤销 | 403 | 403 | 允许 | 403 |
| 旧 M5–M8 配置域写 | 403 | 403 | 允许（`MCHECKER_CONFIG_MANAGEMENT=on`） | 403 |
| 旧域只读 | 503/只读 | 503/只读 | 503/只读（readonly 档） | 503/只读 |

说明：`config_registry_write` 是全局管理员能力，不存在“空间管理员/空间查看者”。普通成员在 UI 看到只读横幅，服务端仍强制 403，不靠隐藏按钮代替鉴权。
