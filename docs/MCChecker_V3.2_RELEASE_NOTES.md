# MCChecker V3.2 更新说明

本版以用户提供的 V3.2 配置原型及配套前端设计为基线，完成配置文件、软件版本、版本标准、机台参数、更新和记录的统一工作流。代码版本标识为 `3.2.0`。外部环境验收与本地交付分开，不将系统内保存解释成向真实设备下发。

## 默认工作区首页修复

修复默认工作区打开配置管理时出现“workspace_id 不能为空”：文件首页读取更新摘要时，将内部默认存储作用域转换为 Sync 的明确工作区标识。默认工作区管理员/访客及文件更新相关12项回归通过。

## 前端原型对照修正

配置页按指定V3.2 HTML重新对照：移除额外宿主页签，统一文件标题和创建动作；恢复参数分段筛选与直接对比，分页设置回到底部；导出使用设置/预览两栏及字段弹窗；文件更新改为五列表格和原型页签顺序；操作记录改为表格。侧栏文件在配置管理中继续打开文件管理，其他模块的文件入口保持原行为。原型截图与真实服务截图分别保存，前端168项及四尺寸工作面几何检查用于防止再次偏离。

## 页面与常用操作

- 配置管理默认显示配置文件列表，与左侧文件入口共用真实文件身份。文件可建立配置或显式关联旧配置；同名重传不会接管原配置历史。
- 文件内提供版本演进、更新管理、操作记录。版本关系图保留，支持缩放及局部横纵滚动；层级列表按软件版本合并机台的正式配置和目标草稿。
- 点击版本或机台进入完整参数页。版本提供标准参数、初始参数、使用该版本的机台和修改记录；机台提供参数和修改记录。历史快照与访客保持只读。
- 新建软件版本直接进入标准参数页。只读参数对比可带入未暂存编辑；修改记录展示保存说明、时间与可追溯操作人，并可打开独立历史快照。
- 参数表提供目录、名称及文件字段搜索、差异筛选、30/50/100 项分页、字段列和密度设置。数值保留精确文本，布尔值、0、空字符串、null 和未设值分开处理。
- 编辑自动准备或继续草稿，底部集中提供取消、暂存和核对并保存。保存前查看实际值及取值方式变化，并可填写说明。离开可继续编辑、放弃本次修改或暂存并离开；清除已暂存草稿需使用明确的更多操作。
- 新建机台只填写编号和选择软件版本，采用本版最新保存标准。更新到其他标准只选目标，比较真实原标准、当前草稿和新标准；保持值保留，需要处理的冲突先选择，再进入编辑和正式保存。
- 普通导入使用真实文件，核对字段、类型和值，未知字段必须明确处理。仅名称模式只核对已有字段；新增参数仍在参数管理完成，不按相似名称自动创建。
- 导出自动带入当前已保存记录，选择模板后预览和下载。有草稿时明确选择先保存或导出上次保存配置，后者保留正在编辑的内容。生成独立文件，不修改模板和原文件。

## 更新与异常处理

文件内更新的来源、候选和运行均限定当前文件；全量操作明确区分当前文件与整个工作区。连接和计划仍使用真实服务，工作区计划不会伪装成单文件设置。

候选核对同时展示正式配置、当前活动草稿及来源新值。草稿在预览后被其他客户端修改时返回409，保留已选处理方式并要求重新核对；不会比较旧标准后覆盖新草稿。写入草稿后仍显示待保存，只有本软件版本正式保存值与候选相符才移出待处理。

普通参数并发冲突按编辑前、服务器最新和本次修改核对，独立修改保留，双方都改动的项目先选择。保存部分失败保留已完成草稿和剩余输入，未知网络结果先读回；正式保存、升级和放弃使用稳定请求回执，避免重复操作。来源缺失时机台仍可查看，继续升级须明确选择真实原标准。

## 接口与数据兼容

接口详情见同包 `docs/V3_API.md`。

- 新增只读文件、版本标准、机台索引及参数查询，服务端筛选后分页，不建立平行存储。
- 配置可选关联 `file_id`。旧配置、旧链接与无文件归属的数据继续保留；不通过名称猜测关联。
- 标准按本软件版本选择最新已保存记录，不取其他版本的全局最新记录。机台准备升级草稿时，正式列表仍显示原已保存版本。
- 新手工版本使用独立初始参数语义；没有软件提供的初始快照时保持为空，首次保存标准不伪造初始值。旧版本沿原记录契约读取。
- 保存、合并、导入和导出继续复用既有领域接口与历史格式。管理员与访客两档权限、工作区/机型隔离、不可变历史及真实设备边界保持。
- 运行增加可选启动目标快照用于文件归属。缺少该信息的旧运行留在工作区历史；不按今天的来源设置改写过去归属。

本地 Python、前端和真实服务浏览器结果记录在开发仓库的 `docs/MCChecker_V3.2_PLAN.md` 与 `docs/evidence/v3.2/`。覆盖文件身份、保存与回执、导入/导出、草稿升级与放弃、已有草稿候选、409、权限撤回、工作区切换、四尺寸及3,248项参数。

## 使用与运维

运行代码保持 Python 3.9 标准库及原生 JavaScript，无新增运行时依赖。按同包使用手册启动；配置管理入口为 `/index.html#/p/default/configv3?workspace=default`。使用现有生产数据前仍应遵循既有备份流程；本版不自动迁移旧配置归属，不包含用户数据或凭据。
