## 已确定的产品方向

文件、机台、参数三个视角共用身份和保存记录。文件页查看参数和迭代历史，机台页集中查看该机台的全部配置文件，参数页比较一个或多个参数的名称、属性和值。机台采用准确基线记录，主线更新不会自动覆盖机台。管理系统已保存内容不代表设备已安装或回读成功。

版本默认列表，保存关系按需查看；目录可收起，来源和历史详情按需打开，参数表占据主要空间。沿用现有浅灰/白/蓝与紧凑表格风格，不增加新的应用框架、组件库或装饰性文案。

更新来源的普通流程为“粘贴链接 → 识别预览 → 核对文件对应 → 保存”。手工提取规则、地址组成、连接与自动更新按需展开。读取与保存配置分别执行：获取生成待核对内容，保存仍有版本校验和操作记录。设计覆盖单文件、网页列表、JSON/XML 清单和已有压缩包支持；当前原型只使用 `.invalid` 样例，不代表真实网页适配完成。
