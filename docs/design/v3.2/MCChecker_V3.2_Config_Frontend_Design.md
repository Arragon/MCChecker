# MCChecker V3.2 配置管理前端设计

日期：2026-11-09。对应交互原型：`MCChecker_V3.2_Config_Prototype.html`。

本版基于用户提供的 V3.1 原型与设计说明，优化配置管理的工作区布局、参数编辑效率和状态表达，并让示例中的草稿、比较、保存、历史与导出保持一致。交付物是可评审的独立前端原型，未修改生产应用，也未连接真实配置中心或机台。

## 1. 打开与评审

HTML 的样式、图标、示例模型和交互脚本全部内嵌，无外部字体、脚本或资源依赖。下载后用现代浏览器打开即可。文件内设置了禁止网络连接的内容安全策略；文件导入在浏览器本地读取，XML / JSON 导出通过 Blob 生成下载。

右上角“交互原型 · V3.2”可以切换管理员 / 访客、模拟下一次保存失败、模拟并发修改或更新会话过期。“查看大数据与快捷键”中可以把当前文件扩展到 3,248 项示例参数。上述控件属于原型演示设置，不是生产页面的业务入口。

示例数据只在本次打开期间存在。刷新或关闭页面会还原；“暂存草稿”也不代表已写入真实服务。

保留既有的“配置文件 → 软件版本 → 机台”结构，保留关系图、层级列表与完整对象页面。日常任务在页面内完成，新建、差异核对和冲突选择使用阶段性弹窗。

| 版本图 | 缩紧列与行的基础间距，支持缩放和局部滚动；实际采用的历史标准另有快照节点 | 同时表达版本演进与准确的参数来源 |
| 参数工作台 | 目录与表格分区；支持名称 / 字段搜索、差异筛选、列显示、行密度、分页和参数详情 | 兼顾少量参数与 3,000+ 参数场景 |

视觉继续使用系统中文字体、浅灰页面、白色数据工作面和蓝色操作。蓝色表示主操作、当前选择和编辑；琥珀色表示草稿及待核对；绿色表示已保存或成功；红色表示错误。状态同时包含文字。数值、字段路径和记录标识使用等宽字体，常规标签沿用系统字体。

主要颜色为 `#f5f7fa` 页面背景、`#ffffff` 工作面、`#e3e8ef` 分隔线、`#182230` 正文、`#596779` 次要文字、`#225ce0` 主操作。组件沿用紧凑的 6–8px 圆角；弹窗使用更柔和的 12px 圆角。图标为统一线宽的内嵌 SVG，不依赖 Unicode 字符代替图标。

## 3. 不能改变的业务语义

所有对象按工作区、文件和稳定对象标识隔离。两个文件中都有 MC-001，用来验证名称相同不会导致串读。切换全局工作区后，文件、版本、机台、更新候选和记录切换到各自独立的数据集合。

初始参数、已保存标准、机台已保存记录、历史快照和草稿分别存在。初始参数与历史快照只读；手工修改标准不会覆盖初始参数。新建版本只记录可选的上一版本关系，不复制其参数。新建版本的手工保存也不会被擅自视为软件初始快照；没有初始数据时显示明确空状态。

查看态显示已保存值，继续草稿后才显示草稿内容。暂存保存完整编辑会话，包括参数值、取值方式、目标版本及来源。取消本次编辑保留原先已经暂存的草稿；显式“放弃已暂存草稿”才清除它。尚未正式保存的新对象放弃其唯一草稿时，会移除该临时对象，避免留下无法保存的空壳。

机台按已保存的软件版本归属。MC-002 的 691 草稿不会提前改变其 690 正式归属，也不会被计入“使用 691 版本的机台”。保存成功后才迁移归属、创建新快照并清理草稿。

“使用标准值”“单独设置”“保持此值”是显式属性，不能根据数值是否相等推断。机台保存的是配置快照；版本标准后来发生变化，不会自动改写机台。普通比较使用该版本最新保存标准，升级比较使用机台实际采用的来源修订；历史机台页使用其历史来源修订，不能取当前版本替代。

## 4. 页面与交互

### 配置文件与版本演进

文件首页显示文件名、配置名称、软件版本、机台数、草稿 / 待核对状态及最近保存时间。侧栏的文件入口与首页共用同一文件身份。

关系图横向排列软件版本，纵向排列初始参数、版本标准及各机台。实线表达已记录的版本或保存演进，虚线表达参数来源。若机台引用某版本的旧标准修订，图中单独出现“来源标准快照”，避免把它错误地连到最新标准。草稿通过文字与琥珀色虚线框表达。

搜索支持版本号和机台编号。筛选图时，匹配对象关联的历史版本或草稿目标可能保留为“关联上下文”。层级列表按“软件版本 → 机台”排列，同一机台的正式配置与草稿合并在一行。搜索用独立折叠状态，清除后不覆盖普通列表的折叠设置。返回同一文件时保留图 / 列表视图、筛选、滚动位置和相关入口焦点。

### 参数页面

版本页提供标准参数、初始参数、使用此版本的机台、修改记录；机台页提供参数与修改记录。对象在完整页面展示，面包屑提供回到文件的入口。

参数目录、搜索与差异筛选共同作用。搜索匹配参数名称和文件字段。筛选可显示全部、与参考值不同、本次修改。尚未提供初始快照的新标准，不显示无依据的“与初始值不同”筛选。

表格支持每页 30 / 50 / 100 项，防止一次渲染数千个编辑控件。默认展示文件字段，可在显示设置中隐藏。参数名称可打开详情，展示数据类型、范围、单位及完整字段。数值使用数值输入框，布尔值使用明确的 true / false 选项，文本按文本处理。

编辑时保留上次保存值，新增编辑值列，并在底部集中提供取消、暂存、核对并保存。输入错误在对应单元格显示，保存前再次校验。修改后再恢复原值且未显式更改取值方式，不会仅因曾经触碰过字段就计为修改。

### 导入、升级、保存与导出

| 流程 | 原型行为 |
| --- | --- |
| 导入 | 选择本地 XML / JSON 或使用示例文件，核对已匹配参数、完整字段、类型和值，再进入编辑。未知字段必须明确忽略；仅名称模式不覆盖值。 |
| 更新到其他标准 | 以同一份捕获的配置 / 草稿生成比较和后续编辑，展示原标准、当前内容、新标准。显式标准项跟随新标准，固定项保留，自定义项根据差异要求选择。 |
| 暂存与离开 | 有本次未暂存修改时提供继续编辑、放弃本次修改、暂存并离开。版本变化和来源变化同样属于编辑会话。 |
| 正式保存 | 核对实际值与取值方式变化、可填写修改说明，然后生成新的独立记录。保存标准不会自动改变已有机台，也不代表下发设备。 |
| 保存失败 | 模拟失败后保留输入，显示可重试的错误。并发修改时比较值、取值方式以及版本 / 来源，先合并再重新核对保存。 |
| 导出 | 选择 XML / JSON 示例模板，生成预览，再下载与预览相同的文本。有草稿时明确选择保存后导出或导出已保存配置。访客和历史快照只走只读导出。 |

升级中的“当前内容”会明确指出是草稿 / 编辑值，避免核对页面显示正式值、实际合并却使用草稿值。冲突选择以稳定选项值记录，不通过字符串是否包含某个数字猜测选择。

XML 示例导出保留字段路径层级并转义文本；JSON 示例导出保留嵌套结构以及数字、布尔和文本类型。这里生成的是新示例文件，未声称保留任意生产模板中的注释、未知字段或格式。

### 更新管理与记录

MachineConfig.xml 提供一条 SDA 示例来源，支持路径、频率、启用 / 暂停设置，立即获取、运行状态、失败记录和待处理内容。“全部更新”明确只处理当前工作区已配置的示例来源。

更新候选先进入核对。已有版本标准草稿时，核对表同时展示正式值、草稿值和来源新值；会覆盖草稿的冲突必须明确选择。未采用的候选保留，只有正式保存值与候选相符的字段才从待处理内容中移除。

标准参数.json 展示未配置来源的空状态，其设置按钮不编辑另一个文件的来源。正式的来源创建、认证、计划调度和运行服务留待生产接入。

文件操作记录可按对象、操作、操作人或 IP 搜索。对象“修改记录”提供独立保存快照。地址中的历史 ID 必须属于当前文件与当前对象；不能借用另一个对象的修订号改变页面内容。

## 5. 状态、响应式与可访问性

| 状态 | 当前设计 |
| --- | --- |
| 正常与成功 | 对象标题、版本、保存状态、时间和主操作集中；成功使用状态反馈 |
| 加载 | 来源获取显示骨架和文字，更新按钮防重复触发 |
| 空状态 | 区分无搜索结果、无机台、无历史、无初始快照、无更新来源、无待处理变化 |
| 输入错误 | 保留值，字段显示错误并关联辅助技术描述；修正或改用标准值后重算校验 |
| 保存 / 更新失败 | 保留编辑或已获取内容，提供重试；均为明确的模拟场景 |
| 只读 | 初始、历史和访客不提供写入路径；导出不能绕过权限进入保存 |
| 升级 / 并发冲突 | 展示冲突双方内容，未选择不能继续；模式和目标来源也参与合并 |
| 草稿 | 查看态与草稿分离，草稿目标不改变正式版本归属 |
| 长内容 | 表格分页与局部滚动，长字段换行；图保持局部双向滚动 |

桌面端保留侧栏、参数目录和表格并列。中等宽度缩小侧栏与目录。手机宽度隐藏宿主侧栏，目录变为横向选择，表格在工作区内滚动；对象动作与保存栏允许换行。小屏及粗指针设备的主要按钮、展开、分页、页签和编辑控件设置至少 44px 点击高度。

弹窗使用原生 `dialog`，带标题、模态语义和关闭按钮。复杂比较先聚焦标题，普通表单先聚焦输入。Esc 关闭；关闭或重绘后恢复合理焦点。状态反馈使用 `role=status`，错误使用 `role=alert`，输入错误与控件关联。支持减少动画偏好；高频操作没有入场动画。

上述内容是已实现的结构与交互意图。实际像素布局、浏览器焦点行为、触屏手感和辅助技术表现仍需浏览器验收。

## 6. 组件影响与生产接入

| 范围 | V3.2 原型职责 | 正式接入约束 |
| --- | --- | --- |
| Shell、导航与工作区 | 统一上下文、可拦截的离开、路由恢复 | 接入宿主真实工作区 / 机型；不修改无关宿主页面 |
| 图与层级表 | 共同使用对象、版本和明确来源 | 使用真实保存记录与版本关系，不从展示位置推断来源 |
| 参数表与编辑栏 | 分页、类型控件、差异和完整编辑会话 | 复用真实参数定义、单位、范围、字段与权限 |
| 弹窗与状态 | 新建、比较、冲突、错误、焦点返回 | 作为配置管理局部组件 / 变体；不得直接覆盖所有宿主弹窗 |
| 配置模型 | 文件隔离、快照、草稿、来源和并发模拟 | 后端持久化、版本校验、真实审计、幂等与结果回读 |
| 导入 / 导出 / 更新 | 本地解析、示例模板、模拟来源 | 接入生产解析、参数定义维护、模板保真、登录保活及任务调度 |

蓝色、间距、边框、字体和局部组件在此原型内统一复用。正式集成应先与项目现有 tokens 和组件对齐，把配置管理差异限制在本地组合或明确变体；本次没有授权把宿主所有页面同步改版。

生产接入不应直接复用内存数据模型作为真实后端。所有接口需携带工作区、机型、文件、对象和记录的稳定身份；后端应执行权限及并发校验。网络结果不明时先回读状态再决定重试，不能把前端超时直接视为保存失败。更新会话保活、闲置失效后的账密重新登录、凭据保护及任务运行记录仍需服务端完成。

本轮未实现未知参数定义的新建、生产任意模板保真、真实 SDA 认证与网络访问、计划定时执行、持久化草稿、多人协作、真实设备下发及宿主其他页面。这些边界在相关原型入口或说明中明确区分。
