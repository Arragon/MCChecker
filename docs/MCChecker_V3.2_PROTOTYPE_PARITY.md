# V3.2 前端原型对照修正

本轮针对“生产前端没有严格按指定 HTML 实现”的反馈。基准为 `docs/design/v3.2/MCChecker_V3.2_Config_Prototype.html`，不是旧 R6、V3.1 或此前自行调整的界面。指定原型保持原字节；生产数据、权限和状态继续使用真实接口。

## 已修正的结构偏差

| 原型要求 | 修正 |
| --- | --- |
| 单层全局环境与面包屑 | 配置页隐藏宿主的额外页面页签；56px桌面顶栏、208/224px侧栏、42px面包屑。手机54px顶栏、38px面包屑；768px保留166px侧栏 |
| 文件标题集中呈现上下文和动作 | 文件名、配置名称、版本与机台摘要集中；新建机台和软件版本移到文件标题区，不再占独立一行 |
| 文件首页 | 搜索文件名或配置名称、文件数、全部更新、白色文件表格；兼容旧配置入口放在页脚 |
| 参数工作台 | 172px目录、16px间隔；768px为128px目录、10px间隔；搜索框、直接对比、导入及显示设置集中在工具栏 |
| 筛选与分页 | 全部、差异、本次修改使用可见分段按钮，不再换成下拉选择；每页项数与翻页放在表格底部 |
| 文件侧栏 | 配置管理中点击文件继续进入该文件管理，不误开旧文件查看器；迟到响应及分页精确匹配有回归；旧模块保留原文件筛选 |
| 导出 | 移除四步流程条；左侧设置、右侧预览，下载在预览标题区；字段对应通过独立弹窗查看和编辑，修改后旧预览立即失效 |
| 文件内更新 | 独立文件标题与文件页签；更新来源、待处理变化、运行记录按原型顺序；来源表使用来源、目标版本、更新计划、最近结果、操作五列 |
| 更新设置 | 顶部更新设置与立即更新；来源维护、连接、工作区计划集中在设置入口。真实计划仍明确属于整个工作区 |
| 操作记录 | 改为操作/对象、变更内容、操作人、时间、查看表格；历史恢复及详情保留 |
| 弹窗 | 520/720/960px层级宽度、12px圆角、带分隔线的标题、正文及页脚，手机16px内边距及局部滚动；不改其他模块的共享弹窗 |

## 对照证据

原型截图由 `scripts/capture_v32_reference.py` 从未修改 HTML 生成，覆盖1366×768、1920×1080、768×1024、375×812的九个页面，共36张。真实界面截图由隔离服务浏览器场景产生，放在同一目录 `docs/evidence/v3.2/parity/`。

- 参数页：`prototype-parameters-1366.png` 对照 `v32-parameters-1366.png`；手机对应 `*-375.png`。
- 版本演进：`prototype-evolution-1366.png` 与实际关系图截图。
- 文件首页：`prototype-files-1366.png` 对照 `v32-file-home.png`。
- 文件更新：`prototype-updates-1366.png` 对照 `v32-file-updates.png`。
- 字段弹窗：`v32-export-fields-1366.png`，另有四种尺寸的全部弹窗布局清单。

原型使用固定示例；实际截图使用隔离真实API数据。文件名、参数数、版本、操作人、时间及缺失初始快照如实显示，不复制示例数据冒充生产能力。宿主真实身份和其他模块入口保留，原型演示设置不进入生产。

## 验证

前端168项及编辑/图谱15项通过。完整服务浏览器报告为 `parity/acceptance.json`，包含39项交互、28个旧路由和1项API。四尺寸集中复验为 `parity/confirmation.json`；其中额外断言目录宽度、表格横向起点、面包屑高度和额外页签隐藏，以实际浏览器布局验证指定原型结构，不能仅用功能通过替代。

文件更新范围、真实候选写草稿、正式保存、409、权限撤回、导出保真、工作区切换、3248参数和多版本双向滚动继续走原有真实契约。物理触屏、真实SDA及真实设备不属于本轮视觉对照证据。

发布打包170项检查通过；包内224个源码文件与工作树逐字节一致，Python3.9.11语法边界和差异格式检查通过。清理预览无符合条件条目，未删除路径。本次使用隔离模拟数据拉起真实页面供对照，不改用户原数据。
