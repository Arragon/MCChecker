四种视口通过页面无横向溢出、工作区/表格非零高度、最后一行纵向可达及表格横向末端可达的检查。另以隔离真实服务逐视口检查来源编辑、计划、连接面板及嵌套连接弹窗的高度、最后可用控件与底部操作区，保存截图；几何测试关闭动画以测量最终状态。55 条合成长名称/路径来源通过真实 API 分页，桌面与手机末项可达；手机 Chromium 触摸仿真验证滑动、展开长路径、页签与面板操作。设置/机型与外部工具调用共享弹窗，已检查焦点进入、Esc 和返回。来源读取失败由合成错误注入，重试回到真实 API；窄屏无断点长错误及连接弹窗长错误均可换行。候选长值使用合成响应。真实触屏设备、全部弹窗与全部异常组合仍未穷举；旧 F01–F28 自动化仅证明路由可达，并不证明全部旧功能交互通过。

来源列表 API 当前仅支持机型、类型、状态和关键字筛选，且服务端分页；固定配置和软件版本不在查询契约中。不能把当前页客户端过滤称为全工作区筛选；实现该原型能力需要另行调整服务端接口，本次计划明确不修改公开 API，故保留为设计与契约冲突。

候选逐项冲突存在基线选择缺口：当前界面只提交 `config_id` 和 `draft_id`，未提交 `base_revision_id`。实测未冻结草稿时 API 默认将当前草稿作为基线，基线 1、当前 2、候选 3 的测试若不指定基线会得到“采用新值”；显式指定已冻结的基线 1 才产生冲突并可执行 `use_new`。接口支持该可选参数，但目前缺少用户已确认的基线来源/选择规则，不能猜测并自动传入；因此真实 API 冲突决议与合成界面决议分开记录，不宣称完整界面端到端通过。本次按计划停止该项扩展。
